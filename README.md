# 自动点击

自动点击是一款面向 Android 的辅助点击和自动化工具。项目基于无障碍服务执行点击、滑动、系统动作、截图识别等操作，通过悬浮窗提供运行控制，主要用于重复点击、步骤化自动化流程，以及在指定应用内按事件触发执行。

> 请在合法、合规、明确授权的场景中使用本工具。无障碍服务仅用于执行用户主动配置的辅助操作。

## 当前版本

- 应用版本：`1.0.2`
- 包名：`org.xiaobu.autoclick`
- 最低系统：Android 7.0，部分截图识别能力需要 Android 11 及以上。

## 功能概览

### 连点器

- 支持单点或多点顺序点击。
- 支持点击间隔、点击持续时长、最大点击次数。
- 支持悬浮指针定位和悬浮控制面板。
- 支持长按拖动调整指针顺序。
- 支持配置保存、加载、导入、导出和删除。

### 自动点击器

- 支持按步骤编排自动化流程。
- 支持一次执行或重复执行。
- 支持步骤添加、编辑、删除、拖动排序。
- 支持坐标选择悬浮窗，可从目标页面直接选取坐标。
- 支持配置保存、加载、导入、导出和删除。
- 支持小窗模式下使用主要弹窗，选择应用、编辑步骤、选择动作等弹窗内容可滚动，底部按钮保持可用。

自动点击器支持的动作：

- 等待
- 等待出现
- 等待消失
- 单击
- 双击
- 长按
- 滑动
- 上滑
- 下滑
- 左滑
- 右滑
- 打开应用
- 返回
- 主页
- 最近任务
- 通知栏
- 快捷设置
- 锁屏

步骤支持的目标类型：

- 坐标：通过选点悬浮窗或手动坐标执行。
- 文字查找：通过无障碍节点文本查找目标。
- 文字识别：通过截图和 ML Kit 中文文字识别查找目标，Android 11 及以上可用。
- 图片识别：通过截图和本地模板匹配查找目标，不依赖 ML Kit 图片识别 SDK。

等待出现和等待消失用于等待目标状态变化。它们支持文字查找、文字识别和图片识别，不支持坐标目标。

步骤失败策略：

- 失败停止：默认策略，步骤失败后停止当前流程。
- 失败继续：步骤失败后继续执行后续步骤。
- 失败重试：步骤失败后按配置的重试次数重新执行。

### 触发器

- 支持选择一个或多个目标应用。
- 支持按多个无障碍事件触发。
- 支持页面关键词过滤和精确匹配。
- 支持冷却时间，避免同一规则频繁重复执行。
- 支持启用、停用、保存、导入、导出和删除规则。
- 支持复用自动点击器的步骤动作和失败策略。
- 触发器执行时会串行执行步骤，避免多个触发规则同时抢占无障碍手势。

触发事件类型：

- 页面跳转
- 页面渲染完成
- 页面滚动
- 控件点击
- 文字变化

包含图片识别目标的触发器或自动点击器配置在导出、导入后会清空本地图片 URI，需要重新选择图片。

### 设置

- 支持切换主题色。
- 内置赤、橙、黄、绿、青、蓝、紫主题，默认使用紫色主题。

## 权限说明

应用依赖以下权限和系统能力：

- 悬浮窗权限：用于显示连点器、自动点击器和坐标选择悬浮控制界面。
- 无障碍权限：用于执行点击、滑动、系统返回等辅助操作，并监听触发器事件。
- 查询应用列表权限：用于选择触发器目标应用和打开应用动作的目标应用。
- 网络权限：用于加载图片识别步骤中可能配置的网络图片地址。
- 前台服务权限：用于坐标选择悬浮窗等前台服务场景。
- 通知权限：用于 Android 13 及以上的前台服务通知授权。

首页会展示悬浮窗和无障碍权限状态。权限未开启时，相关功能不会进入运行状态，避免配置后无法执行。

## 识别能力说明

### 文字查找

文字查找读取当前窗口和可访问窗口的无障碍节点文本。它不需要截图，速度较快，但依赖目标应用是否向无障碍服务暴露文本节点。

### 文字识别

文字识别使用：

- `com.google.mlkit:text-recognition-chinese:16.0.1`
- ML Kit bundled 中文 OCR 模型
- 无障碍服务截图能力

正式包开启 R8 混淆和资源压缩。为了保证 OCR 在 release 构建中可用，项目已配置：

- ML Kit、VisionKit、Dynamite descriptor 相关 keep 规则。
- `androidResources.noCompress += "tflite"`，避免模型文件被压缩。

### 图片识别

图片识别不是 ML Kit Image Labeling，也没有额外图片识别 SDK。当前实现是：

1. 截取当前屏幕。
2. 加载用户选择的目标图片。
3. 在截图中做像素模板匹配。
4. 匹配成功后返回目标中心点。

图片识别同样依赖 Android 11 及以上的无障碍截图能力。

```bash

```

```powershell
.\gradlew.bat :app:assembleDebug
```

Release 构建：

```powershell
.\gradlew.bat :app:assembleRelease
```

```powershell
.\gradlew.bat :app:testDebugUnitTest
```

## 使用注意

- OCR 和图片识别依赖截图能力，Android 11 以下不可用。
- 不同应用对无障碍节点暴露程度不同，文字查找可能找不到某些自绘界面文本。
- 截图、OCR 和图片匹配比普通坐标点击更耗时，等待类步骤会按目标类型使用不同轮询间隔。
- 触发器不会处理本应用自身产生的无障碍事件，避免自触发循环。
- 当前版本不包含录制功能。
